## 🚀 GitHub Pages দিয়ে চালু করার নিয়ম

1. GitHub-এ `my-kashiani` নামে একটি Repository তৈরি করুন।
2. `index.html` এবং `README.md` ফাইল আপলোড করুন।
3. Repository-র **Settings** খুলুন।
4. **Pages** বিভাগে যান।
5. Source হিসেবে `Deploy from a branch` নির্বাচন করুন।
6. Branch হিসেবে `main` এবং Folder হিসেবে `/(root)` নির্বাচন করুন।
7. `Save` চাপুন।
8. প্রকাশিত হলে `Visit site` দিয়ে ওয়েবসাইট দেখুন।

ওয়েবসাইটের ঠিকানা সাধারণত:

`https://YOUR-USERNAME.github.io/my-kashiani/`

এখানে `YOUR-USERNAME`-এর জায়গায় আপনার GitHub username বসবে।
